所有符号都学完了。这一课不讲新符号，而是把前五课串起来：完整地写一句话要经过哪几步，标点怎么处理，怎么继续往下学。

## 写一句话的三步

以 *Le soir, je lis au bord de l'eau.* 为例：

1. **拆音。** 不看拼写，只听读音：*soir* 是 S·ou·a·R（打开 Sigles 时 *oi* 简写成 a），*lis* 是 L·i（*s* 不发音），*bord* 是 B·o·R（*d* 不发音），*l'eau* 是 L + o。
2. **写辅音骨架。** 辅音的方向和长短固定，先在脑子里排好这些线和半圆。
3. **安放元音。** 按前几课的位置规则把元音挂上去：圆形元音逆时针绕，é/i 和 u/eu 看朝向，鼻元音看象限，遇到角就画圆。

```steno sounds
Le soir, je lis au bord de l'eau.
```

打开 **Edit**，把句子换成你自己的，看工具怎么拆音。如果它拆错了（法语拼写的例外很多），去[主画布](./)里点那个词改正。

## 标点和格式

- **句号**：句与句之间画一个小 ×，或者直接换行。
- **插入语**：前后要和主句分开写。
- **专有名词和数字**：下面画线。
- 其他标点在速记里很少用。

```steno
Pierre arrive à Lyon. Il reste trois jours.
```

## 练习：读句子

先读速记，说出整句，再点 **Show word** 核对。

```read
Nous partons demain matin.
Mon ami a du pain.
Il fait beau.
Elle écrit une page.
```

## 练习：写句子

先在纸上写，再点 **Check**。

```write
Le vent est froid.
Je vais à la mer.
Chaque jour, je lis un peu.
Nous avons un petit jardin.
Le matin, il boit du café.
```

## 接下来怎么练

1. **慢写，准写。** 先保证比例：短笔是长笔的一半，小圆和大圆分清楚。速度是长期练出来的，写得潦草的速记过几天你自己也读不出来。
2. **多读。** 读和写一样重要。把这些课里的「读」练习反复做，直到一眼认出整个词。
3. **转写自己的文本。** 把日记、课堂笔记、喜欢的歌词放进[主画布](./)，对照着抄写。
4. **听写。** 熟练以后，找慢速的法语音频（新闻、播客）边听边写，再对照原文检查。
5. **深入缩写体系。** 教材第二部分讲词缀和更多缩写，是提速的关键，学完这六课后再学。

> 这套课程到这里结束。工具的拆音规则和教材有出入时，以教材为准；如果你发现工具拆错了某个词，可以到 [GitHub](https://github.com/zcanic/duploye-transcriber) 反馈，或者直接在主画布里改正。
