最后一组元音：四个鼻元音，都是**小的四分之一圆**，比上一课的 u、eu 小。四个符号形状相同，靠**所在象限**区分：

| 象限 | 鼻元音 | 常见拼写 |
|---|---|---|
| 左上 | **an** | *an, am, en, em* |
| 右上 | **in** | *in, im, ain, ein, yn* |
| 右下 | **on** | *on, om* |
| 左下 | **un** | *un, um* |

```signs
an in
un on
```

> 拼写里 *n*、*m* 后面紧跟元音或另一个 *n*、*m* 时，就**不是鼻元音**：*ami*、*bonne*、*dune*、*aime* 里的 *m*、*n* 是辅音。工具按这一条拆音，你写的时候也要这样判断。

## 词首：位置和其他元音相反

这是鼻元音唯一的例外。词首的鼻元音画在**和其他元音相反的一侧**。但如果后面接的是**横线（T、D）或往上挑的线（L、R）**，就照常画在原来那一侧。

```steno sounds
anglais ombre invite humble emmêler ennui enlever enrichir
```

需要明确区分时，可以给小弧加重音符号，但实际书写中一般不加：an、on 加尖音符，in、un 加钝音符。

## 词尾：和大四分之一圆同样的规则

接在下行线后面时，**an、in 学 i 的方向，on、un 学 é 的方向**：

```steno sounds
pan pont enfin défunt
```

接在横线后：an、in 朝上，on、un 朝下：

```steno sounds
dans dont
```

接在 L、R 后顺着前进方向；接在半圆后画在外侧：

```steno sounds
quand terrain gond emprunt son nain jeun
```

## 词中

和 u、eu 一样：能区分时，尽量把 on、un 和 an、in 写在词尾时的位置；不出角就顺着后一个辅音；直角、钝角处画圆角。

```steno sounds
ranger compte plancher échanger banque monde tente
```

```steno sounds
abonde fonde danger tomber
```

## 双元音

第一个元音按常规位置写，后面的鼻元音直接接上：

```steno sounds
point loin moins joint
```

## 小结

- 鼻元音是小四分之一圆：an 左上，in 右上，on 右下，un 左下。
- 词首位置和其他元音相反，但在 T、D、L、R 前照常。
- 词尾和词中：和 u、eu 的规则一样（an、in 学 i，on、un 学 é）。
- *n*、*m* 后面跟元音或另一个 *n*、*m* 时，不是鼻元音。
