这一课的目标：认全 Duployé 的辅音和元音，知道每个符号**往哪个方向写、写多长**，然后用最短的单音节词和缩写写出第一句话。

页面里每个带点阵的格子都是活的：点 **Write again** 看它一笔一笔写出来，点 **Edit** 改里面的法语，速记会跟着变。

## 先记住五条原则

1. **只写读音，不管拼写。** 不发音的字母一律不写。*homme* 只有两个音：o 和 M。
2. **辅音的形状和方向固定。** 清浊辅音靠长短区分：短笔正好是长笔的一半。
3. **元音会动。** 元音的形状不变，但写在辅音哪一边、往哪个方向绕，要看前后连的是什么。这是 Duployé 的核心，第 2 课专门讲。
4. **一个词一笔写完。** 中途不提笔，第一个辅音落在书写线上。
5. **除了 L 和 R 往上挑，所有笔画都往下或往右写。**

```steno sounds
homme
```

## 直线辅音

直线辅音有两类。**下行**（plongeantes）从上往下写，**前行**（avançantes）从左往右写。每对里左边是短笔（清音），右边是长笔（浊音）。

```signs
K G P B F V
T D L R
```

> K 和 L 都是斜线，最容易混。K 更陡，**往下**写；L 更平，从左下**往上挑**。在词里，这两笔的走向完全不同。

辅音单独念的时候带一个轻 e：P 念 *pe*，K 念 *que*。所以一个辅音本身就能代表 *que*、*de*、*le* 这样的单音节词：

```steno sounds
que de te le
```

## 半圆辅音

半圆辅音写的是半个圆。M 开口朝右，N 开口朝左，S 开口朝上，J 开口朝下。在半圆里加一个点，就得到另一个音：N 加点是 GN，S 加点是 Z，J 加点是 CH。实际书写中这个点经常省略。

```signs
M N GN
S Z J CH
```

```steno sounds
me ne se je
```

## 元音一览

元音全是圆、半圆和四分之一圆。这里先认形状，位置规则后面几课再学。

| 元音 | 形状 | 例词 |
|---|---|---|
| a | 小圆 | *à*, *ah* |
| o | 大圆 | *au*, *eau*, *haut* |
| ou | 大圆加点（词中常省略点） | *où*, *août* |
| é / i | 小半圆 | *et*, *est* |
| u / eu | 大四分之一圆 | *eu*, *eux* |
| an / in / on / un | 小四分之一圆，按象限区分 | *en*, *on*, *un* |

```signs
a o ou é i u eu
an in on un
```

单个元音也能直接当词用：

```steno sounds
a au ou et eu eux en on un
```

> 法语里 [e] 和 [ɛ] 都写成 é。*est*、*et*、*ait*、*haie* 读音相同，所以写法也相同。速记只记读音，靠上下文区分。

## 第一批缩写（sigles）

最常用的词有约定好的极简写法，**只写一个字母**。这种写法不能从读音推出来，需要死记：

| 词 | 写成 |
|---|---|
| pour | P |
| bien | B |
| faire | F |
| vous | V |
| nous | N |
| tout, tous, toute, toutes | T |
| grand, grande | G |
| Monsieur | M |
| il | i |

```steno sounds
Un pour tous, tous pour un.
```

把上面这个格子切到 **Edit**，改成 *pour vous*、*bien faire*，看看缩写是怎么替换的。

## 小结

- 只写读音。辅音形状、方向固定，长短区分清浊。
- 只有 L 和 R 往上写。
- 单音节词往往就是一个符号。
- sigles 要背到一看就认出来。

下一课学圆形元音 a、o、ou 怎么接在辅音上。这是整套速记最关键的一步。
