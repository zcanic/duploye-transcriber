title: 圆形元音 a · o · ou
lang: fr

辅音的方向是固定的。元音则要「找位置」：同一个小圆 a，接在 P 上和接在 T 上，画的位置不一样。这一课学圆形元音的定位规则。学会之后，后面的半圆元音和四分之一圆元音都按同一个思路来。

三个圆形元音：

```signs
a o ou
```

- **a**：小圆
- **o**：大圆。*au*、*eau*、*haut*、*os* 都读 [o]，都写成它。
- **ou**：大圆加点。在词中间，这个点可以省略。

## 规则一：词首和词尾

元音在词首或词尾时，位置由它连着的那个辅音决定：

| 辅音类型 | 圆圈画在 |
|---|---|
| 下行直线（K G P B F V） | 线的**右边** |
| 前行直线（T D L R） | 线的**上方** |
| 半圆（M N S J…） | 半圆的**里面** |

有个好记的说法：圆圈都按**逆时针**画，所以它总是落在辅音围出来的那一侧。

```steno sounds
abat avoue auto aura amas anneau assaut achat
```

写的时候不提笔：从前一笔的末端顺势绕一圈，再接下一笔。整个词的第一个辅音压在书写线上。

## 规则二：两个辅音之间，没有角

如果前后两个辅音连接处是顺的，没有拐角，比如同方向的两条直线，或者直线接上半圆，元音就保持它在词尾时的位置：

```steno sounds
coke mode poupe donne fauve chape doute pose lors mat
```

## 规则三：两个辅音之间，形成了角

如果前后两个辅音连接处有拐角，圆圈就画在**角的外侧**。这样笔画最顺，也不会和辅音缠在一起：

```steno sounds
apport ovale accord moral canal somme dommage orage relate
```

## 双元音

两个元音挨在一起时，第一个按常规位置写，第二个顺着手的自然走向接上去：

```steno sounds
chaos boa zoo noua rouage
```

## oi 写成 a

*oi* 读 [wa]。Duployé 不把它当成双元音，**直接写成 a**：

```steno sounds
oiseau fois toit loi voir toile soir
```

## 专有名词和数字

专有名词和数字下面画一条线。句子之间用一个小 × 隔开。

```steno
Monsieur Charles passera six jours à Bâle.
```

## 小结

- 词首、词尾：下行线的右边，前行线的上方，半圆的里面。都逆时针画。
- 两个辅音之间：没有角就保持词尾位置；有角就画在角外侧。
- 双元音：第一个按常规写，第二个顺手接上。*oi* 写成 a。
