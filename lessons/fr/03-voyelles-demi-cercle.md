上一课的圆形元音是一整个圈。这一课的 é 和 i 只有**半个小圆**，像一个小钩子。两者形状一样，靠**朝向**区分：i 向一边弯，é 向另一边弯。

```signs
é i
```

- **é**：代表 [e] 和 [ɛ]。*é*、*è*、*ê*、*ai*、*ei*、*et*、*-er*、*-ez* 读这两个音的，都写它。本站的村规（第 1 课）会在开口的 [ɛ] 上加一个小重音，写作 è。
- **i**：代表 [i]，包括 *y*。

## 词尾：i 和 é 朝相反方向

这一条最重要，先学它。词尾的小钩**接上辅音时不出角**，然后：

| 接在… | i 弯向 | é 弯向 |
|---|---|---|
| 下行线和半圆后（K P F M N S J…） | 右 | 左 |
| 横线后（T D） | 上 | 下 |

对比两行。上面一行都是 i，下面一行都是 é：

```steno sounds
qui habit vie lit dit ami ni
```

```steno sounds
quai abbé fait les des mes année
```

*qui* 和 *quai*、*dit* 和 *des*、*habit* 和 *abbé*，每一对的辅音完全相同，只有钩子的方向不同。

## 词首：和圆形元音同一侧

元音在词首时，小钩画在**和圆形元音相同的位置**（下行线右边、横线上方、半圆里面）。词首的 i 和 é 容易混，需要区分时，在 i 上面点一个点。

```steno sounds
égal ébauche iglou hibou image ignore
```

## 词中：三种情况

**1. 两个辅音之间没有角**：保持词尾时的朝向。

```steno sounds
vite riche tir dites faites régie terre dette
```

**2. 保持不了词尾朝向时**：就把小钩朝**后一个辅音的方向**画，并和它形成一个角。

```steno sounds
type ride site débat raide cette
```

**3. 两个辅音形成锐角，或是两条方向不同的斜线时**：不再单独画小钩，而是**把那个角画圆**，圆角本身就代表元音。

```steno sounds
guère cher même rival
```

> 第 3 种「画圆角」是 Duployé 很聪明的地方：元音几乎不占笔画，却又能读出来。写的时候注意圆角要圆，别写成尖角，否则就读不出元音了。

## 双元音

元音挨着元音时，彼此相连，并尽量避免多余的角：

```steno sounds
oui aérer hier jouir créer poète
```

## 省音（élision）

*l'*、*j'*、*c'*、*d'*、*qu'* 这类带省音符号的字母要不要和后面的词连成一笔？规则只有两条：

- 后面是**单音节词**，或者是**以圆形元音（a、o、ou）开头**的词（包括缩写）：**连写**；
- 其他情况：**分开写**。

```steno
j'ai c'est l'air s'y m'y
```

```steno
l'habit d'aller l'avis qu'avec l'affaire
```

```steno
l'école s'étonne d'idée
```

最后一组的 *école*、*étonne*、*idée* 都以 é 或 i 开头，不是圆形元音，所以 *l'*、*s'*、*d'* 单独写。

## 小结

- é、i 是同一个小钩，**朝向**决定是哪个：词尾 i 朝右（横线后朝上），é 朝左（横线后朝下）。
- 词首和圆形元音同侧；需要时 i 上加点。
- 词中：没角就保持词尾朝向；不行就朝后一个辅音拐；锐角或两条不同方向的斜线之间，直接画圆角。
- 省音字母只和单音节词、圆形元音开头的词连写。
