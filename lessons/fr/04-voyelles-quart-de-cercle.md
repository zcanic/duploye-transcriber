---
title: 大四分之一圆 u · eu
lang: fr
---

u 和 eu 是**四分之一个大圆**，比上一课的小钩更长、更舒展。如果你学会了 é 和 i，这一课只是换一个形状：规则几乎一一对应。

```signs
u eu
```

- **u**：[y]，法语的 *u*、*û*，以及 *eu* 读 [y] 的少数词（*j'ai eu*）。
- **eu**：[ø] 和 [œ]，*eu*、*œu*、*œ* 都写它。

把一个圆分成四份：**eu 在左上，u 在右下**。

## 词首：和其他元音同一侧

接上辅音时不出角，画在**和圆形元音、半圆元音相同的位置**。需要区分时，在 eu 里面点一个点。

```steno sounds
Hugues oeuf humide usine unir humour
```

## 词尾：u 像 i，eu 像 é

接在 P、B、F、V、K、G 这些下行线后面时，**u 的方向和 i 一样，eu 的方向和 é 一样**。这就是为什么先学了 é 和 i：

```steno sounds
pu vu du mu connu
```

```steno sounds
peut veut deux ceux heureux
```

接在 L、R（往上挑的线）后面时，弧线顺着前进方向；接在半圆后面时，画在半圆的**外侧**：

```steno sounds
aigu accru issue échu fameux fâcheux
```

## 词中

和 é、i 一样：

- 不出角就顺着**后一个辅音的方向**画大弧；
- 两个辅音之间是**直角或钝角**时，直接把角画圆。

```steno sounds
bureau refuser culte mur nul juger ruche dune veuf
```

```steno sounds
peuvent durée chute aucune occupé
```

> 在词中，能区分 eu 和 u 的时候，就尽量把它写在词尾时的位置。读的时候，这样更不容易混。

## 双元音

第一个元音按常规位置写，后面的元音直接接上，不出角：

```steno sounds
yeux aïeux saluer muet nuage tuer duel
```

## ui 写成 i（速度简写）

教材的实际写法是把 *ui* 直接写成 **i**，和第 2 课 *oi* 写成 a 是同一个思路：

```steno sounds sigles
lui suis nuit depuis fruit
```

同样会丢信息：*lui* 和 *lit*、*nuit* 和 *nid* 会写成一样。完整写法是 **u + i**，照读音 [ɥi] 把两个元音连起来：

```steno sounds
lui suis nuit depuis fruit
```

画布默认用完整写法，打开 **Sigles** 开关才用简写。

## 小结

- eu 左上，u 右下，都是大四分之一圆。
- 词首和其他元音同侧；词尾在下行线后，u 学 i，eu 学 é；在半圆后画在外侧。
- 词中顺着后一个辅音走；遇到直角、钝角就画圆角。
- *ui* 写成 i。
